# 火车档案 · Train Archive

一个**单人单文件（`index.html`）**的中国铁路档案应用。整个站点只有这一个 HTML，无构建步骤、无后端、无依赖——浏览器直接打开即可用，托管到 GitHub Pages 后即为完整网站。

## 这是什么？

面向铁路爱好者的车站、线路、列车维度档案库。数据以 `localStorage` 持久化，支持浏览、搜索与就地编辑，并内置两套「待开通」专题。

## 页面与路由（hash 路由）

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/` | 首页 | 车站/列车概览 + 全局搜索 |
| `/lines` | 线路档案 | 中国铁路线路 |
| `/trains` | 列车档案 | 运营车次（现行/已停运） |
| `/stations` | 车站 | 车站明细，含 12306 电报码/拼音/城市元数据 |
| `/upcoming` | **待开通车站** | 96+ 在建车站，开通时间倒计时置顶、按年份/阶段分组，跨境走廊标注 |
| `/upcoming-lines` | **待开通线路** | 26 条在建/拟建线路专题，与车站**多对多**关联（一站可属多线，如上海东站/宝山站/天府站） |
| `/contribute` | 投稿 | 提交新线路/列车 |

## 数据与特色

- **车站元数据**：电报码、全拼/短码、城市、序号均来自 12306 `station_name.js`，真实可靠；更名车站（如 甘洛→甘洛南、松江南→上海松江）已做匹配；乘降所与境外站如实标注、绝不编造。
- **国际/跨境预留**：内置 `GLOBAL_SCOPE` 结构，标注中国跨境走廊（中蒙俄 / 中朝 / 中越）与跨境车站，为未来「全球火车档案」预留扩展。
- **多对多关系**：待开通线路 ∷ 车站 双向索引，同一枢纽站会显示于其所属的每一条线路下，并带 `+N` 角标与「共用枢纽站」识别。
- **倒计时置顶**：待开通专题自动把即将开通（2026 年窗口）的内容置于顶部，并分组 2026 / 2027 / 2028 / 远期。

## 本地运行

双击 `index.html`，或启动任意静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/index.html
```
